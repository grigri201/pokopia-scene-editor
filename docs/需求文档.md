# Pokopia 5×5 布景编辑器需求文档

## 1. 项目概述

### 1.1 项目名称

Pokopia 5×5 布景编辑器

### 1.2 项目目标

本工具用于帮助用户制作、编辑和预览 Pokopia 中的 5×5 规模布景。

由于实际布景中，主体区域外侧通常还会放置外立面、屋檐、墙体边缘、植物、遮挡物等额外装饰，而这些装饰也会占用格子，因此编辑器实际提供 **7×7 编辑画布**。

其中：

- 中心 **5×5** 为布景主体区；
- 外围一圈为外围装饰区；
- 用户可以在完整 **7×7** 画布上摆放素材、管理建筑层、标记技能需求，并预览最终效果；
- 对外仍将该布景定义为 **5×5 布景**。

---

## 2. 核心概念

### 2.1 尺寸定义

| 概念 | 尺寸 | 说明 |
|---|---:|---|
| 布景主体区 | 5×5 | 用户主要设计的核心布景内容 |
| 外围装饰区 | 外围 1 圈 | 用于放置外立面、边缘装饰、遮挡物等 |
| 实际编辑画布 | 7×7 | 包含 5×5 主体区与外围装饰区 |
| 最终预览范围 | 7×7 | 展示完整布景效果 |
| 布景规模标注 | 5×5 | 对外仍称为 5×5 布景 |

### 2.2 画布区域划分

7×7 画布由中心主体区和外围装饰区组成。

```text
外 外 外 外 外 外 外
外 主 主 主 主 主 外
外 主 主 主 主 主 外
外 主 主 主 主 主 外
外 主 主 主 主 主 外
外 主 主 主 主 主 外
外 外 外 外 外 外 外
````

说明：

* `主` 表示 5×5 主体布景区；
* `外` 表示外围装饰区；
* 外围装饰区用于承载外立面、边缘装饰和其他占格素材；
* 用户可以在主体区和外围区都放置素材；
* 预览时应展示完整 7×7 画布，同时突出显示 5×5 主体边界。

### 2.3 坐标规则

建议内部使用 0-based 坐标。

7×7 画布坐标范围：

```text
x: 0-6
y: 0-6
```

5×5 主体布景区坐标范围：

```text
x: 1-5
y: 1-5
```

外围装饰区规则：

```text
x = 0 或 x = 6
y = 0 或 y = 6
```

只要某个格子位于最外圈，即属于外围装饰区。

### 2.4 建筑层规则

建筑层用于表达 Pokopia 中“从低往高建造”的高度层，不等同于通用设计软件中的自由叠放层。

建筑层编号使用 0-based 层数：

```text
0层：地面、基础地块、底层占位
1层：第一层建筑、主体道具、低处装饰
2层-n层：更高建筑、屋顶、上层装饰、遮挡结构
```

显示和预览时应按层号从 **0层到 n层** 展示。层号越大表示位置越高；上下关系由建筑层层号决定，而不是由用户任意拖拽排序决定。

## 3. 用户目标

用户希望通过编辑器完成以下事情：

1. 在 7×7 画布中设计一个完整的 5×5 Pokopia 布景；
2. 在中心 5×5 主体区摆放主要道具、地块、建筑和装饰；
3. 在外围一圈摆放外立面、边缘装饰、遮挡物等额外素材；
4. 通过建筑层功能按 0层到 n层编辑从低到高的布景内容；
5. 从素材选择框中快速搜索、筛选并选择当前使用的素材；
6. 在素材或地块上标记哪里需要使用百变怪技能改变布景；
7. 编辑完成后，可以预览俯视图和正视图；
8. 保存或导出完整布景数据，便于后续查看、分享或继续编辑。

### 4.1 核心功能

| 技能选择框    | 必需   | 用于标注哪里需要使用百变怪技能       |
| 俯视图预览    | 必需   | 展示完整 7×7 顶视效果         |

## 5. 画布编辑需求

### 5.1 画布基础要求

编辑器应提供一个 7×7 的格子画布。

每个格子可用于放置一个或多个素材，具体是否允许叠放由素材类型和建筑层规则决定。

画布需要支持：

* 显示 7×7 网格；
* 区分中心 5×5 主体区和外围装饰区；
* 高亮当前鼠标悬停格；
* 高亮当前选中格；
* 显示已放置素材；
* 显示技能标记；
* 显示当前编辑建筑层内容；
* 可切换显示单建筑层或全部可见建筑层。

### 5.2 主体区

主体区是布景的核心区域，尺寸为 5×5。

主体区可放置：

* 地面；
* 家具；
* 建筑；
* 植物；
* 装饰；
* 功能性道具；
* 需要百变怪技能改变的素材。

主体区需要在画布上有明显边界，避免用户误以为外围装饰区也属于主体规模。

### 5.3 外围装饰区

外围装饰区为主体区外侧一圈，共 24 个格子。

外围装饰区可放置：

* 外立面；
* 墙体边缘；
* 屋檐；
* 栅栏；
* 背景遮挡物；
* 边缘植物；
* 边框装饰；
* 延伸出来但会占格的道具；
* 需要百变怪技能处理的外部装饰。

外围装饰区中的内容应参与：

* 编辑；
* 建筑层管理；
* 俯视图预览；
* 正视图预览；
* 保存；
* 导出；
* 技能标记统计。

### 5.4 画布视觉要求

| 区域      | 显示方式            |
| ------- | --------------- |
| 5×5 主体区 | 正常网格背景，作为主要编辑区域 |
| 外围装饰区   | 使用略浅、略暗或虚线边框样式  |
| 主体边界    | 显示明显边界线         |
| 当前选中格   | 高亮显示            |
| 鼠标悬停格   | 显示轻量高亮          |
| 技能标记格   | 显示百变怪技能图标或特殊角标  |
| 锁定建筑层内容  | 降低透明度或禁止交互      |

## 6. 素材摆放需求

### 6.1 基础摆放

用户从素材选择框中选择素材后，可以在画布格子中点击放置。

摆放时应记录：

* 所在建筑层；
* 所在坐标；
* 所属区域；
* 素材 ID；
* 素材名称；
* 素材分类；
* 朝向；
* 是否需要技能；
* 技能类型；
* 其他备注信息。

### 6.2 删除素材

用户可以删除指定格子中的素材。

删除方式可以包括：

* 选中格子后点击删除；
* 使用橡皮擦工具；
* 右键删除；
* 快捷键删除。

### 6.3 替换素材

当用户在已有素材的格子上放置新素材时，系统应支持以下策略之一：

1. 直接替换当前建筑层中的旧素材；
2. 弹出确认；
3. 根据素材类型判断是否允许叠放；
4. 在不同建筑层中允许同坐标按高度上下共存。

推荐默认规则：

* 同一建筑层、同一格子、同一位置只能有一个主素材；
* 不同建筑层可以在同一格子按高度上下叠加；
* 是否允许叠加由素材类型决定。

### 6.4 素材旋转

如果素材支持方向变化，应允许用户设置朝向。

可支持的方向：

```text
上 / 右 / 下 / 左
```

或：

```text
front / right / back / left
```

### 6.5 素材移动

用户可以将已放置素材移动到其他格子。

移动时应保留：

* 素材 ID；
* 建筑层；
* 技能标记；
* 朝向；
* 备注；
* 其他属性。

## 7. 建筑层管理需求

### 7.1 建筑层基础功能

用户可以创建多个建筑层，每个建筑层可以单独编辑。

建筑层表示布景在垂直方向上的高度层。0层为最低层，通常承载地面和基础地块；1层、2层直到 n层依次表示更高的建筑或装饰内容。

建筑层需要支持：

* 新建建筑层，默认创建为当前最高层号 + 1；
* 删除建筑层；
* 重命名建筑层；
* 复制建筑层；
* 调整素材所属建筑层；
* 显示 / 隐藏建筑层；
* 锁定 / 解锁建筑层；
* 设置当前编辑建筑层。

### 7.2 建筑层属性

每个建筑层应包含以下属性：

| 字段    | 说明                |
| ----- | ----------------- |
| 建筑层 ID | 唯一标识              |
| 层号    | 0-based 整数，0层为最低层，n层为最高层 |
| 建筑层名称  | 用户可编辑，默认可使用“0层”“1层”等 |
| 是否可见  | 控制预览和编辑显示         |
| 是否锁定  | 锁定后不可编辑           |
| 建筑层类型  | 可选，如地面基础层、主体建筑层、上层建筑层等 |
| 建筑层内素材 | 当前建筑层中所有已摆放素材      |

### 7.3 推荐默认建筑层

编辑器可以默认创建以下建筑层：

| 层号 | 默认名称 | 用途 |
| ---: | --- | --- |
| 0 | 0层 / 地面基础层 | 放置地面、路径、基础地块、底层占位 |
| 1 | 1层 / 主体建筑层 | 放置第一层建筑、家具、植物、低处装饰 |
| 2 | 2层 / 上层建筑层 | 放置屋顶、上层建筑、较高装饰、遮挡结构 |
| 3-n | 扩展建筑层 | 按需要继续向上扩展更高层建筑内容 |

默认建筑层不是强制限制，用户应可以自行新增、删除或重命名。技能标记和备注应作为素材 / 格子的属性记录，不应作为独立建筑层。

### 7.4 建筑层编辑规则

* 当前只能编辑一个激活建筑层；
* 建筑层必须按层号从 0层到 n层显示和预览；
* 层号越大表示建筑位置越高；
* 隐藏建筑层不参与当前画布显示，但数据仍保留；
* 锁定建筑层可显示，但不可编辑；
* 删除建筑层时需要二次确认，并明确该层素材是删除还是移动到其他建筑层；
* 建筑层上下关系由层号决定，不提供任意拖拽排序；
* 预览时默认按 0层到 n层展示所有可见建筑层。

## 8. 素材选择框需求

### 8.1 基础功能

素材选择框用于让用户选择当前要摆放的素材。

素材选择框需要支持：

* 展示素材列表；
* 展示素材缩略图；
* 展示素材名称；
* 模糊搜索；
* 分类筛选；
* 标签筛选；
* 适用区域筛选；
* 技能相关筛选；
* 选择当前素材；
* 查看素材详情。

### 8.2 素材列表字段

素材选择框建议包含以下字段：

| 字段    | 说明               |
| ----- | ---------------- |
| 素材图标  | 展示素材缩略图          |
| 素材名称  | 素材显示名称           |
| 素材分类  | 地面、植物、建筑、外立面、装饰等 |
| 适用区域  | 主体区 / 外围区 / 通用   |
| 标签    | 可旋转、可叠放、需要技能等    |
| 技能选择框 | 标注本次放置是否需要百变怪技能  |
| 操作    | 选择、查看详情等         |

### 8.3 模糊搜索

用户可以通过输入关键词搜索素材。

搜索范围包括：

* 素材名称；
* 素材分类；
* 素材标签；
* 素材别名；
* 备注说明。

示例：

用户输入：

```text
树
```

可匹配：

* 小树；
* 大树；
* 果树；
* 树篱；
* 边缘树丛。

### 8.4 筛选功能

素材选择框应支持以下筛选项：

| 筛选项    | 说明              |
| ------ | --------------- |
| 全部素材   | 显示所有素材          |
| 地面     | 显示地面类素材         |
| 建筑     | 显示建筑类素材         |
| 家具     | 显示家具类素材         |
| 植物     | 显示植物类素材         |
| 装饰     | 显示装饰类素材         |
| 外立面    | 显示外立面和边缘装饰      |
| 主体区素材  | 适合放在 5×5 主体区的素材 |
| 外围装饰素材 | 适合放在外围一圈的素材     |
| 技能相关素材 | 默认需要或常用百变怪技能的素材 |
| 通用素材   | 主体区和外围区均可使用的素材  |

### 8.5 技能选择框

素材选择框中需要有单独一列作为“技能选择框”。

该选择框用于标注当前素材在放置时是否需要使用百变怪技能改变布景。

交互逻辑：

1. 用户选择某个素材；
2. 用户勾选或取消勾选该素材行中的技能选择框；
3. 用户在画布中放置该素材；
4. 系统将该格子记录为是否需要百变怪技能；
5. 已标记技能的格子在画布和预览中显示特殊标记。

需要注意：

* 技能选择框影响的是“本次放置记录”；
* 同一个素材在不同格子中可以有不同的技能标记；
* 用户可以在放置后单独修改某个格子的技能标记；
* 技能标记应跟随素材数据保存。

## 9. 百变怪技能标记需求

### 9.1 技能标记目的

技能标记用于帮助用户记录：

* 哪些位置需要使用百变怪技能；
* 哪些素材需要通过百变怪技能改变布景；
* 哪些外立面或装饰需要特殊处理。

### 9.2 技能标记显示

在画布中，带有技能标记的格子需要有明显提示。

可选显示方式：

* 显示百变怪技能图标；
* 在格子右上角显示角标；
* 使用特殊边框；
* 使用特殊背景；
* 鼠标悬停时显示“需要百变怪技能”。

### 9.3 技能标记编辑

用户应可以通过以下方式修改技能标记：

* 在素材选择框中勾选后放置；
* 选中已放置素材后切换技能标记；
* 使用专门的技能标记工具点击格子；
* 在属性面板中修改。

### 9.4 技能标记数据

每个已放置素材应记录：

| 字段            | 说明           |
| ------------- | ------------ |
| requiresSkill | 是否需要技能       |
| skillType     | 技能类型         |
| skillNote     | 技能备注         |
| areaType      | 位于主体区还是外围装饰区 |

示例：

```json
{
  "x": 0,
  "y": 3,
  "areaType": "outer",
  "assetId": "asset_wall_outer_001",
  "assetName": "外立面墙体",
  "requiresSkill": true,
  "skillType": "ditto_transform",
  "skillNote": "需要使用百变怪技能改变外立面"
}
```

## 10. 预览需求

### 10.1 预览类型

编辑器需要提供两种预览模式：

| 预览模式 | 说明              |
| ---- | --------------- |
| 俯视图  | 从上往下查看完整 7×7 布景 |
| 正视图  | 从正面查看布景外观和层级效果  |

### 10.2 俯视图预览

俯视图应展示完整 7×7 画布。

俯视图需要支持：

* 显示主体区内容；
* 显示外围装饰区内容；
* 显示 5×5 主体边界；
* 显示所有可见建筑层；
* 支持只预览当前建筑层；
* 显示技能标记；
* 支持开启或关闭网格线；
* 支持开启或关闭主体边界线。

推荐开关：

```text
显示网格：开 / 关
显示主体边界：开 / 关
显示技能标记：开 / 关
仅显示当前建筑层：开 / 关
```

### 10.3 正视图预览

正视图应展示完整布景的正面效果。

正视图需要体现：

* 主体区内容；
* 外围外立面内容；
* 建筑层从 0层到 n层的上下关系；
* 外围装饰对主体区的遮挡或延展；
* 需要百变怪技能的位置；
* 素材的高度或前后层级关系。

如果外立面是布景视觉效果的重要组成部分，正视图默认应包含外围装饰区。

### 10.4 预览中的建筑层规则

预览时应遵循以下规则：

* 仅显示可见建筑层；
* 锁定建筑层仍可显示；
* 隐藏建筑层不显示；
* 建筑层按层号从 0层到 n层渲染；
* 层号越大的素材显示为更高位置的内容；
* 技能标记可独立开关；
* 用户可以选择预览当前建筑层或全部可见建筑层。

## 11. 属性面板需求

### 11.1 格子属性

当用户选中某个格子时，属性面板应显示该格子的详细信息。

包括：

| 字段     | 说明           |
| ------ | ------------ |

## 14. 交互流程

### 14.1 放置素材流程

```text
用户打开编辑器
↓
系统显示 7×7 画布
↓
用户在素材选择框中搜索或筛选素材
↓
用户选择素材
↓
用户选择是否勾选技能选择框
↓
用户点击画布中的格子
↓
系统将素材放置到当前建筑层的对应格子
↓
系统记录坐标、区域、素材、建筑层和技能标记
```

### 14.2 创建建筑层流程

```text
用户点击“新建建筑层”
↓
系统创建一个空白建筑层，层号为当前最高层号 + 1
↓
用户输入建筑层显示名称
↓
系统将该建筑层设为当前编辑建筑层
↓
用户开始在该建筑层中摆放素材
```

### 14.3 预览流程

```text
用户完成编辑
↓
用户点击“预览”
↓
用户选择俯视图或正视图
↓
系统读取所有可见建筑层
↓
系统按建筑层层号从 0层到 n层渲染画布
↓
系统显示完整 7×7 布景效果
↓
系统可选择显示主体边界和技能标记
```

## 16. 验收标准

### 16.1 画布验收

* 编辑器显示 7×7 画布；
* 中间 5×5 区域被明确标记为主体布景区；
* 外围一圈被明确标记为外围装饰区；
* 用户可以在主体区和外围区都摆放素材；
* 系统能够正确识别每个格子属于主体区还是外围区；
* 用户可以选中、编辑、删除格子中的素材。

### 16.2 建筑层验收

* 用户可以创建新的更高建筑层；
* 用户可以重命名建筑层；
* 用户可以删除建筑层；
* 用户可以将素材移动到不同建筑层；
* 用户可以隐藏和显示建筑层；
* 用户可以锁定和解锁建筑层；
* 当前编辑建筑层中的内容可以独立编辑；
* 预览按建筑层层号从 0层到 n层展示；
* 隐藏建筑层不显示在预览中；
* 锁定建筑层不可编辑但可以显示。

### 16.3 素材选择框验收

* 用户可以看到素材列表；
* 用户可以通过关键词模糊搜索素材；
* 用户可以按分类筛选素材；
* 用户可以按适用区域筛选素材；
* 用户可以按是否技能相关筛选素材；
* 用户可以选择某个素材作为当前编辑素材；
* 素材选择框中存在单独的技能选择框列。

### 16.4 技能标记验收

* 用户可以在素材选择框中勾选技能选择框；
* 勾选技能后放置的素材会记录为需要百变怪技能；
* 用户可以对已放置素材修改技能标记；
* 需要技能的格子在画布中有明显标识；
* 需要技能的格子在俯视图和正视图中可以显示；
* 导出数据中正确记录技能标记。

### 16.5 预览验收

* 用户可以打开俯视图预览；
* 俯视图显示完整 7×7 画布；
* 俯视图可以显示 5×5 主体边界；
* 用户可以打开正视图预览；
* 正视图展示主体区和外围装饰区的整体效果；
* 预览内容遵循建筑层显示、隐藏和 0层到 n层展示规则；
* 预览中可以显示或隐藏技能标记。

### 16.6 数据保存验收

* 保存数据中包含 5×5 主体尺寸；
* 保存数据中包含 7×7 画布尺寸；
* 保存数据中包含外围扩展格数；
* 保存数据中包含建筑层信息；
* 保存数据中包含每个素材的坐标；
* 保存数据中包含每个素材所属区域；
* 保存数据中包含每个素材的技能标记；
* 重新打开保存数据后，画布状态应能完整还原。

## 17. 非功能需求

### 17.1 易用性

* 用户应能清楚理解主体区和外围装饰区的区别；
* 用户应能快速搜索和选择素材；
* 用户应能直观看到当前编辑建筑层；
* 用户应能直观看到哪些格子需要百变怪技能；
* 常用操作应尽量减少点击次数。

### 17.2 性能

* 7×7 画布规模较小，常规编辑操作应即时响应；
* 素材搜索应在输入后快速返回结果；
* 建筑层切换和预览切换不应出现明显卡顿；
* 素材数量较多时，素材列表应支持分页或虚拟滚动。

### 17.3 可扩展性

系统设计应支持未来扩展：

* 更大的布景尺寸；
* 可配置外围扩展格数；
* 更多视角预览；
* 更多技能类型；
* 更多素材分类；
* 素材批量导入；
* 布景模板；
* 分享和协作编辑。

## 18. 待确认问题

### 18.1 外围装饰区是否固定为 1 格宽？

当前需求按：

```text
5×5 主体区 + 外围 1 圈 = 7×7 编辑画布
```

进行设计。

如果未来存在更复杂布景，例如 5×5 主体但需要 2 圈外立面装饰，则可以将 `outerPadding` 设计为可配置项。

### 18.2 同一格子是否允许同建筑层叠放多个素材？

当前建议规则为：

* 同一建筑层、同一格子默认只允许一个主素材；
* 不同建筑层允许同坐标按高度上下叠放；
* 是否允许叠放可由素材类型决定。

### 18.3 正视图的生成规则是否需要严格模拟游戏视角？

当前需求只要求正视图能展示布景正面效果。

后续需要确认：

* 是否按真实游戏视角渲染；
* 是否使用等距视角；
* 是否只是简化的正面排布图；
* 是否需要处理遮挡关系。

### 18.4 技能选择框是标注素材，还是标注格子？

当前建议：

* 素材选择框中的技能选择框用于决定“本次放置是否需要技能”；
* 最终技能标记记录在具体格子 / 素材实例上；
* 同一个素材在不同格子中可以有不同技能标记。
